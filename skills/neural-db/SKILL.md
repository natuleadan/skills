# Neural DB

An enhanced SQL database engine with **native vector search**, distributed as a
standalone program (not a library).

## What it is

- A buildable program: you build and run it; it is not an importable package.
- SQL storage with native vector search for embeddings.
- Designed to run as its own service alongside the rest of your stack.

## Distribution

- Prebuilt archives per version (Linux and macOS).
- A container image for server deployments.
- GPU acceleration is planned; CPU works today.
