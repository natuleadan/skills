# Security Policy

## Supported versions

The latest release on `main` receives security fixes. Older versions are not
supported.

## Reporting a vulnerability

Do not open a public issue. Use the private advisory form:

https://github.com/natuleadan/skills/security/advisories/new

Include the affected version, a minimal reproduction and the impact. If the
report involves a dependency, name the package and version.

## Response

We acknowledge the report, triage it and coordinate disclosure after a fix is
available.

## Scope

This repository contains skill instructions and Node scripts. It does not ship a
service, a database or credentials.
